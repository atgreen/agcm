# v0.3.0

Feature release adding color themes and an About box, plus a large batch of TUI fixes and internal cleanup.

## New Features

### Color Themes

The TUI now ships with selectable color themes: `auto`, `dark`, `light`, `dracula`, `solarized`, and `mono`.

- Press `t` in the TUI to cycle themes; the choice is saved to your config
- Set `ui.theme` in `config.yaml` to pin a theme (`auto` picks dark or light from the terminal background)

### About Box

- Press `a` in the TUI for an About box with version, author, license, and links for reporting bugs and feature requests
- `agcm --help` now shows author, license, and homepage in its footer

### Config Options Now Honored

Two documented config keys that previously had no effect now work:

- `api.timeout` - HTTP client timeout (default: 30s)
- `ui.page_size` - default `list cases` limit when `--limit` is not given (default: 25)

## Fixes

- `Ctrl+U`/`Ctrl+D` now page the case list as advertised in the help screen
- Mouse clicks inside the filter dialog now land on the right field: hit-testing and the product dropdown follow the dialog's actual on-screen position instead of assuming the top-left corner
- Panes no longer render two columns wider than the terminal
- The STATUS column shrinks gracefully on narrow terminals
- Wide characters (CJK, emoji) truncate correctly everywhere in the TUI; previously some columns counted bytes or runes instead of display width
- Refreshing while paginated case pages are in flight no longer duplicates or misplaces rows; stale pages are dropped and re-requested
- Styled text and OSC-8 hyperlinks survive dialog overlays intact
- The status bar hints and help screen are rendered from the key map, so they can't drift from the actual bindings
- `agcm show` no longer fetches case comments twice

## Changes

- **Removed the `export_case` MCP tool.** It returned exactly the same markdown as `get_case`; use `get_case` instead.
- Bundle export (`B` in the TUI, `export cases --bundle`) is now shared code with test coverage; CLI progress output is slightly simplified

## Internal

- Removed roughly 1,300 lines of dead and duplicated code across the API client, auth, config, export, and TUI packages
- New tests for bundle export, list paging keys, filter dialog positioning, and pinned-size frame rendering
