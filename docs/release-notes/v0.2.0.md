# v0.2.0

Feature release adding MCP server for AI assistant integration, shell completions, and configurable debug logging.

## New Features

### MCP Server (`agcm mcp`)

agcm can now run as a [Model Context Protocol](https://modelcontextprotocol.io/) server, allowing AI assistants like Claude to interact with Red Hat support cases directly.

```bash
agcm mcp    # Start MCP server over stdio
```

To use with Claude Code or Claude Desktop, add to your MCP settings:

```json
{
  "mcpServers": {
    "agcm": {
      "command": "agcm",
      "args": ["mcp"]
    }
  }
}
```

**Available tools:**
- `list_cases` - List and filter support cases
- `get_case` - Get full case details with comments and attachments
- `search` - Search cases, solutions, and knowledge base articles
- `get_solution` - Get a KB solution by ID
- `get_article` - Get a KB article by ID
- `export_case` - Export a case to markdown

### Shell Completions (`agcm completion`)

Generate tab-completion scripts for your shell:

```bash
agcm completion bash
agcm completion zsh
agcm completion fish
agcm completion powershell
```

Run `agcm completion --help` for per-shell installation instructions.

### Configurable Debug Logging

- Debug log now defaults to `~/.cache/agcm/debug.log` (respects `$XDG_CACHE_HOME`) instead of the hardcoded `/tmp/agcm-debug.log`
- New `--debug-log` flag to specify a custom log file path
- New `debug.log_file` config option in `config.yaml`
- Export debug output now goes to the same log file instead of stderr
- The debug log path is printed to stderr when `--debug` is enabled
